# Estimator API security — October 20, 2026

Status: proposed branch changes; production unchanged.

## Changes
All three API routes now share exact trusted-origin and JSON-object checks plus actual UTF-8 body limits for both raw and Vercel-parsed JSON. The request Host header cannot authorize an arbitrary origin. Production accepts estimator.midsizeai.com and deployment-specific VERCEL_URL/VERCEL_BRANCH_URL origins; localhost is accepted only outside production.

Limits: lead intake 8 KiB, Street View lookup 2 KiB, visualization JSON 4.4 MB (below the Vercel function request limit). Visualization no longer silently truncates image text and requires consent === true. Existing provider timeouts, server-only credentials, lead allowlists, and browser security headers are retained.

Rate-limit maps are capped at 5,000 clients, expire old entries, count without unbounded arrays, and reject new clients when at capacity. These remain instance-local fallback limits, not shared quotas or authentication. Header spoofing by non-browser clients remains possible.

Added five regression tests covering malicious origins/types/bytes, bounded limiters, strict consent, and successful mocked lead/Street View/visualizer responses. Tests pass without sending lead data or making paid provider requests. Added pinned CodeQL and CI workflows, weekly GitHub Actions Dependabot checks, credential-file ignore rules and SECURITY.md. This static repository has no npm dependencies; no dependency install is needed to run its tests.
